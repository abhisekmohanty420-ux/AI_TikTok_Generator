# AI TikTok Generator 🎬

## About the Project

AI TikTok Generator is a Python-based project designed to automate the creation of short-form videos for platforms like TikTok, Instagram Reels, and YouTube Shorts. The main goal of this project is to simplify video creation by converting text-based content into engaging short videos with minimal manual effort.

The application uses Python and Flask to provide a web interface where users can submit their content and upload files. Each submission is organized into a unique folder using UUID, making file management easier. The project also aims to automate text-to-audio conversion and video reel generation.

## Key Features

- Upload and manage user files.
- Generate unique IDs for each video project.
- Organize uploaded files into separate folders.
- Text-to-audio conversion workflow.
- Automated short-video generation workflow.
- Track completed tasks to avoid repeated processing.

## Technologies Used

## Project Goal

The goal of this project is to build an AI-powered video generation system that reduces the time and effort required to create short-form social media content.

This project is currently under development, and new features and improvements will be added over time.
